# ML Projects

A collection of machine learning projects (computer vision, audio, classification), each in its own folder with full original commit history preserved.

- [int8-ldmresnet-retinal-segmentation](int8-ldmresnet-retinal-segmentation) — retinal image segmentation with an int8-quantized LDM-ResNet
- [AudioDiarization](AudioDiarization) — speaker diarization on audio
- [FormClassification](FormClassification) — classification of legal documents/forms
- [HouseRatings](HouseRatings) — scores house quality from an image
- [Diabetes-Prediction-System](Diabetes-Prediction-System) — predicts diabetes risk from patient data
- [SMS-Spam-Classifier](SMS-Spam-Classifier) — classifies SMS messages as spam or ham
- [Twitter-Sentiment-Analysis](Twitter-Sentiment-Analysis) — sentiment analysis on tweets
